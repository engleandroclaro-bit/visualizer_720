# Audio Visualizer 720p (Safety Version)

Um visualizador de áudio e sincronizador de letras (LRC) desenvolvido em Python utilizando **Pygame**, **Pygame GUI** e **FFmpeg**.

## 🚀 Funcionalidades
- **Renderização em tempo real:** Visualização de ondas sonoras e sincronização de letras via arquivos `.lrc`.
- **Interface Gráfica (GUI):** Controles integrados para fácil navegação e renderização.
- **Exportação de Vídeo:** Integração com FFmpeg para gerar vídeos prontos para publicação.

## 🛠️ Pré-requisitos
- **Python 3.11+**
- **FFmpeg** instalado e configurado nas variáveis de ambiente do sistema.
